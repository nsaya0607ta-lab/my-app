# 資産管理アプリ（Asset）

「今いくら持っているか」だけでなく、**「今自由に使えるお金」と「未来の資産」** を可視化する
個人向け資産管理アプリです。ビルド不要のバニラJS（ESモジュール）＋ localStorage で動作します。

エントリーポイント: `finance/index.html`

## 特に重視した3機能

1. **クレジットカードの引落管理** — カードごとに締日・引落日・引落口座を設定。利用を登録すると
   「実際に銀行から引き落とされる日」まで資金を拘束せず、`次回引落予定` として一覧表示します。
2. **将来の資産シミュレーション** — 収入・固定支出・積立投資（想定年利）・ボーナスから、
   3か月〜10年先の資産推移を自動計算し折れ線グラフで表示します。
3. **自由に使えるお金（可処分資金）の自動計算** — 損益計算書形式で
   `収入 − 支出（カード支払予定含む）＝ 自由に使える金額` を月ごとに算出します。

## 主な機能

- ダッシュボード（合計資産・シークレットモード・口座サマリー・引落予定・資産推移）
- 口座管理 / 収支の記録（検索・フィルター）/ 固定収支 / カテゴリー管理
- 損益計算書 / 分析（円・棒・折れ線）/ カレンダー（給料日・引落日・固定収支）
- 通知（明日のカード引落・給料日・予算超過）
- データ管理（バックアップ／復元 / CSV入出力 / 初期化）
- ダークモード対応・スマホ片手操作前提のレイアウト
- 「将来」タブ内に **収支シミュレーション** と **投資将来予測** の2画面を統合（詳細は後述）
- 収支シミュレーションは **口座別の将来残高**（銀行・現金・証券口座現金・NISA・個別株）まで内訳表示（詳細は後述）

### 証券口座（現金・元本・評価額・保有銘柄・積立）

証券口座 `type: 'securities'` は次の3要素で資産を管理します（`js/securities.js`）。すべて**利用者が入力したデータのみ**から計算し、外部API・ダミー値は使いません。

- **現金** … まだ投資していない現金。銀行→証券の振替はこの現金へ入金され、株式購入で減少します。
- **元本** … 取得額の合計（保有銘柄から自動計算）。
- **評価額** … 保有銘柄の円換算評価額合計。

保有銘柄は2種類を `holdings[]` に `kind` で判別して保持します。

- **個別株（米国株・USD建て）** `{kind:'stock', name, ticker, quantity, costUsd, priceUsd, fxRate, memo}`
  - 評価額(円) = `保有数量 × 現在株価(USD) × ドル円`、取得額(円) = `保有数量 × 取得単価(USD) × ドル円`
  - 損益 = 評価額 − 取得額、損益率 = 損益 ÷ 取得額 × 100
  - 一覧では ティッカー・現在株価(USD)・ドル円・評価額(円)・損益・損益率 を表示（数量表示なし）。
- **インデックス（円建て）** `{kind:'index', name, nisaFrame:'growth'|'tsumitate', cost, value, memo}`
  - 数量・基準価額は管理せず、総元本(円・`cost`)と現在保有額(円・`value`)のみ入力。
  - 損益 = 保有額 − 総元本、損益率 = 損益 ÷ 総元本 × 100
  - NISA区分（成長投資枠／つみたて投資枠）でグループ分けして表示。
  - **毎朝11時（JST）の積立額はこの総元本に積み上がります**（現金から引き、現在保有額にも同額を反映）。

主な機能:

- **株価を更新（手入力）** … 「株価を更新」は各個別株の**現在株価(USD)とドル円を手入力する画面**です（API取得はしません）。
  保存すると評価額・損益・損益率・保有割合が即時に再計算されます。
- **保有割合** … 現金・個別株・インデックスの円換算評価額から構成比を算出（現金割合も表示）。
- **利益率／評価損益** … `利益率 =（評価額 − 元本）÷ 元本 × 100`、`評価損益 = 評価額 − 元本`。
  証券口座を保有している場合、ホーム画面は昨日比・今月比・前年比に代えてこの2指標を表示します。
- **今月の収支とは分離** … 投資の評価損益・元本増減・銀行⇔証券の振替・積立・購入は「今月の収支（収入 − 支出）」には
  一切含めません。株価やインデックスの評価額が上下しても今月の収入・支出・収支は変わらず、評価損益は
  **投資状況カード・証券口座画面・合計資産の内訳** にのみ反映します。株式の売却益・配当金も自動では収支に
  含めず、利用者が収入取引として明示的に登録した場合のみ今月の収入へ反映します。ホーム画面は
  `今月の収支`（収入・支出・収支差額）と `投資状況`（元本・評価額・評価損益・利益率）を別カードで表示します。
- **個別株購入** … 購入金額(円)＝`株数 × 購入単価(USD) × ドル円`。現金を減らし、取得数量・取得単価へ反映します。
- **インデックス積立（任意）** … `accumulations[]` にON/OFF・毎日の積立額・開始/終了日を保存。**日本時間11:00**を境に
  前回処理日から当日まで日ごとに追いかけて実行し、現金から積立額を引いて対象ファンドの総元本・保有額へ加算、
  成否を `accumHistory[]`（成功／失敗（現金不足））に記録します（設定した場合のみ動作）。

金額を変更・保存すると `store.update()` → 再描画で即座に全指標へ反映されます（`securities.js` は純粋関数中心の独立モジュール）。

データはすべて利用端末のブラウザ内（localStorage・ログイン端末ごと）に保存され、再読み込みでも消えません。外部送信は行いません。

### 投資将来予測（`js/futureSim.js`・「将来」タブ内）

収支シミュレーション（固定収支・カード・振替）と証券口座（現金・元本・評価額）を1つの将来資産シミュレーションへ統合したものです。「将来」タブの上部にある `収支シミュレーション / 投資将来予測` セグメントで切り替えます。すべて登録済みデータのみから計算し、外部API・ダミー値は使いません。

- **統合シミュレーション**: `cashflow.js` の収支イベント（固定収支・カード引落・固定振替・将来日付の取引）と、証券口座の積立・購入予定・想定年利による評価額成長を月次で合成し、`銀行残高・証券口座現金・元本・評価額（インデックス/個別株別）・総資産` を一括計算します。
- **銘柄ごとの積立設定**: インデックス銘柄の積立設定（`accumulations[]`）に `頻度（毎日/毎週/毎月）・毎日/毎月の積立額・積立停止日/再開日・積立終了日` を追加。実際の毎朝11時の自動積立もこの設定に対応します。
- **想定年利・計算方式**: インデックス・個別株それぞれに `simAnnualReturn（想定年利%）` と `returnMode（複利/単利）` を保有銘柄に保存。個別株には `年間配当利回り・配当を再投資するか` も設定でき、配当は毎月按分でメイン projection へ反映されます（OFFなら現金化）。
- **個別株の購入予定**: 銘柄ごとに `plannedPurchases[]`（購入予定日・金額・株数・想定年利・保有予定年数）を保存。予定日に証券口座現金→元本・評価額へ自動反映してシミュレーションします。
- **年利シミュレーション**: クイックチップ（5/7/10/15/20/30%・自由入力）とスライダーで想定年利をその場で変更。「一律の想定年利を全銘柄へ適用」トグルで、銘柄ごとの個別設定と一律シナリオを切り替えられます。
- **保有期間シミュレーション**: 1/3/5/10/15/20/30年をワンタップで切替。
- **シナリオ比較**: 保守(5%)・通常(8%)・強気(15%)・自由設定を重ねて比較。
- **将来資産グラフ**: 総資産・現金・証券口座現金・元本・評価額・インデックス評価額・個別株評価額をチップで表示/非表示切替できる複数系列グラフ（`charts.js` の `multiLineChart`）。
- **資産推移の日付指定**: 任意の未来日を選ぶと、その日の銀行残高・証券口座現金・元本・評価額・合計資産・利益率を表示。
- **投資達成予測**: 目標（名称・目標金額・対象指標）を自由に追加でき、最大30年先まで到達予定時期を自動計算。
- **配当金シミュレーション**: 配当利回りを設定した個別株について、再投資あり/なしの評価額・累計配当を比較。
- **年利感度分析**: 基準年利に対して±2/4%した場合の将来資産を一覧表示。
- **積立変更シミュレーション**: 実データを変更せず、毎月の追加投資額をスライダーで仮変更してその場で効果を確認（What-If）。
- **モンテカルロシミュレーション**: ON/OFF切替。年ごとにランダムな年率リターン（正規分布・標準偏差は設定可）で100〜1000回試行し、中央値・90%範囲（p5〜p95）・最悪/最高ケースをファンチャートで表示。
- **AI分析カード**: 目標到達予測・積立増額の効果・現金比率などをルールベースで文章化して表示（外部AI呼び出しはせず、断定せず「参考情報」として提示）。
- **保存プラン**: 保有期間・想定年利・モンテカルロ設定などの前提条件を名前を付けて複数保存し、あとから読み込み・比較できます（口座・保有銘柄そのものは複製しません）。

### 収支シミュレーション（`js/accountSim.js`・「将来」タブ内）

「3年後に合計でいくらか」だけでなく **「どの口座が将来いくらになるか」** を表示する画面です。
`cashflow.js` の収支イベント（固定収支・カード引落・固定振替・将来日付の取引）と、証券口座の積立・購入予定・
想定年利による評価額成長を、**口座ごとのバケツに分けて日次で前進**させます。1日の処理順・資金不足の判定・
評価額成長のタイミングは `futureSim.project` と完全に同じで、両タブの合計・証券口座現金・NISA/個別株評価額は一致します。

画面構成（上から順）:

1. **現在資産サマリー** … 現在資産・可処分・投資その他・選択期間後の予想
2. **将来の合計予想** … 今月末／来月末／3か月後／半年後／1年後／選択期間後。行タップでその時点の口座別内訳
3. **口座別の将来残高** … 口座 × 資産種別で1枚のカード。口座名・現在残高・将来残高・増減額・増減率・**増減の主因**
   （時点チップで 3か月後〜選択期間後を切替。タップで内訳＋月ごとの推移）
4. **資産構成比** … 将来時点の内訳をドーナツ＋横棒で表示
5. **資産推移グラフ** … 合計資産の月次推移
6. **口座別の資産推移** … 全体／銀行／現金／証券口座現金／NISA／個別株を切替。区分内に複数口座があれば口座別の線も重ねる
7. **資金不足警告** … 口座単位。対象口座・不足日・不足額・原因・改善案を表示
8. **シミュレーションの前提** … 対象期間・想定年利・積立設定・銀行→証券の振替・固定収入／固定支出・カード引落予定・将来イベント
9. **現在未払い（カード）／これからの入出金**

口座別の内訳（タップで表示）:

| 区分 | 表示する内訳 |
|---|---|
| 銀行・現金・その他 | 初期残高 / 収入 / 支出・固定費 / カード引落 / 他口座からの振替入金 / 他口座への振替 / 最終予測残高 |
| 証券口座現金 | 初期残高（預り金）/ 銀行からの入金 / その他入金 / 受取配当 / NISA購入 / 個別株購入 / 出金 / 現金不足で実行できなかった購入 / 最終予測残高 |
| NISA・個別株 | 現在評価額 / 積立（購入）累計 / 想定年利 / 運用益 / 投資元本 / 評価損益 / 最終予測評価額 |

#### 二重計上しない集計ルール

```
合計資産 = Σ(非証券口座の残高) + Σ(証券口座の預り金) + Σ(NISA評価額) + Σ(個別株評価額)
```

- **投資元本と評価額** … 元本は評価額の取得額（内訳）なので合計には足さず、「参考」欄に分けて表示します。
- **証券口座現金と投資元本** … 積立で現金が減り同額が元本・評価額へ移るため、別々に足しても二重になりません。
- **銀行→証券の振替** … 口座間の移動として扱い、収入にも支出にも数えません。
- **カード未払いと支出** … カード利用は実際の引落日に銀行残高から引かれるため、未払い額は合計資産から引かず「参考」欄に表示します。
- 丸めは**口座ごとに1回だけ**行い、その丸め済みの値だけを足し上げるため、**口座別内訳の合計と合計資産は必ず1円単位で一致**します。

#### 増減理由の出し方

口座ごとに `収入 / 支出 / カード引落 / 振替入金 / 振替出金 / 積立購入 / 個別株購入 / 運用益 / 受取配当` を累計で保持し、
増加した口座はプラス側、減少した口座はマイナス側の**最大の項目**を「主因」として1行で表示します。

#### 資金不足の判定（口座単位）

- **口座残高** … その口座の残高が初めてマイナスになった日・金額・その日の最大の出金を原因として記録します。
- **証券口座現金** … 購入日の直前残高が購入予定額に満たない場合、その購入は実行せず不足として記録します
  （現金はマイナスにせず、後日まとめ買いもしません＝実際の積立処理と同じ判定）。
  必要な追加振替額は、期間中に発生した**証券口座現金の最大不足額**（1円単位の整数）です。
