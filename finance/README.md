# 資産管理アプリ（Asset）

「今いくら持っているか」だけでなく、**「今自由に使えるお金」と「未来の資産」** を可視化する
個人向け資産管理アプリです。ビルド不要のバニラJS（ESモジュール）＋ localStorage で動作します。

エントリーポイント: `finance/index.html`

## 特に重視した3機能

1. **クレジットカードの引落管理** — カードごとに締日・引落日・引落口座を設定。利用を登録すると
   「実際に銀行から引き落とされる日」まで資金を拘束せず、`次回引落予定` として一覧表示します。
2. **将来の資産シミュレーション** — 収入・固定支出・積立投資（想定年利）・ボーナスから、
   3か月〜10年先の資産推移を自動計算し折れ線グラフで表示します。
3. **自由に使えるお金（可処分資金）の自動計算** — 損益計算書形式で
   `収入 − 支出（カード支払予定含む）＝ 自由に使える金額` を月ごとに算出します。

## 主な機能

- ダッシュボード（合計資産・シークレットモード・口座サマリー・引落予定・資産推移）
- 口座管理 / 収支の記録（検索・フィルター）/ 固定収支 / カテゴリー管理
- 損益計算書 / 分析（円・棒・折れ線）/ カレンダー（給料日・引落日・固定収支）
- 通知（明日のカード引落・給料日・予算超過）
- データ管理（バックアップ／復元 / CSV入出力 / 初期化）
- ダークモード対応・スマホ片手操作前提のレイアウト

### 証券口座（現金・元本・評価額・保有銘柄・積立）

証券口座 `type: 'securities'` は次の3要素で資産を管理します（`js/securities.js`）。

- **現金** … まだ投資していない現金。銀行→証券の振替はこの現金へ入金され、株式購入で減少します。
- **元本** … 実際に投資した合計金額。手動編集でき、個別株購入・積立で自動加算されます。
- **評価額** … 保有銘柄の時価評価額合計（`保有数量 × 現在株価`）。毎日自動更新されます。

主な機能:

- **保有銘柄** … `holdings[]` に `{name, ticker, kind:'index'|'stock', quantity, avgPrice, memo, price, prevClose}` を保存。
  区分（インデックス／個別株）で色分け表示し、現在価格・評価額・前日比・損益・損益率を一覧します。
- **株価の自動取得** … 起動時、当日未取得なら `/api/stocks/quote`（Finnhub・サーバー側でAPIキー保持）で
  ティッカー設定済み銘柄の株価を取得し評価額を再計算。取得できない銘柄はスキップし、他の更新は止めません。
- **インデックス積立** … `accumulations[]` にON/OFF・毎日の積立額・開始/終了日を保存。**日本時間23:00**を境に、
  前回処理日から当日まで日ごとに追いかけて実行（キャッチアップ方式。クライアントアプリのため起動時に確定）。
  現金から積立額を引き元本へ加算し、成否を `accumHistory[]`（成功／失敗（現金不足））に記録します。
- **個別株購入** … 現金から購入額を引き元本へ加算、保有数量・平均取得単価を更新します。
- **利益率／評価損益** … `利益率 =（評価額 − 元本）÷ 元本 × 100`、`評価損益 = 評価額 − 元本`。
  証券口座を保有している場合、ホーム画面は昨日比・今月比・前年比に代えてこの2指標を表示します。

`securities.js` は純粋関数中心の独立モジュールで、`fetchQuotes()` を差し替えれば別データソースにも対応できます。

データはすべて利用端末のブラウザ内（localStorage・ログイン端末ごと）に保存され、再読み込みでも消えません。外部送信は株価取得を除き行いません。
