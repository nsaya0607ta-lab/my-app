# 資産管理アプリ（Asset）

「今いくら持っているか」だけでなく、**「今自由に使えるお金」と「未来の資産」** を可視化する
個人向け資産管理アプリです。ビルド不要のバニラJS（ESモジュール）＋ localStorage で動作します。

エントリーポイント: `finance/index.html`

## 特に重視した3機能

1. **クレジットカードの引落管理** — カードごとに締日・引落日・引落口座を設定。利用を登録すると
   「実際に銀行から引き落とされる日」まで資金を拘束せず、`次回引落予定` として一覧表示します。
2. **将来の資産シミュレーション** — 収入・固定支出・積立投資（想定年利）・ボーナスから、
   3か月〜10年先の資産推移を自動計算し折れ線グラフで表示します。
3. **自由に使えるお金（可処分資金）の自動計算** — 損益計算書形式で
   `収入 − 支出（カード支払予定含む）＝ 自由に使える金額` を月ごとに算出します。

## 主な機能

- ダッシュボード（合計資産・シークレットモード・口座サマリー・引落予定・資産推移）
- 口座管理 / 収支の記録（検索・フィルター）/ 固定収支 / カテゴリー管理
- 損益計算書 / 分析（円・棒・折れ線）/ カレンダー（給料日・引落日・固定収支）
- 通知（明日のカード引落・給料日・予算超過）
- データ管理（バックアップ／復元 / CSV入出力 / 初期化）
- ダークモード対応・スマホ片手操作前提のレイアウト

### 証券口座（現金・元本・評価額・保有銘柄・積立）

証券口座 `type: 'securities'` は次の3要素で資産を管理します（`js/securities.js`）。すべて**利用者が入力したデータのみ**から計算し、外部API・ダミー値は使いません。

- **現金** … まだ投資していない現金。銀行→証券の振替はこの現金へ入金され、株式購入で減少します。
- **元本** … 取得額の合計（保有銘柄から自動計算）。
- **評価額** … 保有銘柄の円換算評価額合計。

保有銘柄は2種類を `holdings[]` に `kind` で判別して保持します。

- **個別株（米国株・USD建て）** `{kind:'stock', name, ticker, quantity, costUsd, priceUsd, fxRate, memo}`
  - 評価額(円) = `保有数量 × 現在株価(USD) × ドル円`、取得額(円) = `保有数量 × 取得単価(USD) × ドル円`
  - 損益 = 評価額 − 取得額、損益率 = 損益 ÷ 取得額 × 100
  - 一覧では ティッカー・現在株価(USD)・ドル円・評価額(円)・損益・損益率 を表示（数量表示なし）。
- **インデックス（円建て）** `{kind:'index', name, nisaFrame:'growth'|'tsumitate', cost, value, memo}`
  - 数量・基準価額は管理せず、総元本(円・`cost`)と現在保有額(円・`value`)のみ入力。
  - 損益 = 保有額 − 総元本、損益率 = 損益 ÷ 総元本 × 100
  - NISA区分（成長投資枠／つみたて投資枠）でグループ分けして表示。
  - **毎晩23時（JST）の積立額はこの総元本に積み上がります**（現金から引き、現在保有額にも同額を反映）。

主な機能:

- **株価を更新（手入力）** … 「株価を更新」は各個別株の**現在株価(USD)とドル円を手入力する画面**です（API取得はしません）。
  保存すると評価額・損益・損益率・保有割合が即時に再計算されます。
- **保有割合** … 現金・個別株・インデックスの円換算評価額から構成比を算出（現金割合も表示）。
- **利益率／評価損益** … `利益率 =（評価額 − 元本）÷ 元本 × 100`、`評価損益 = 評価額 − 元本`。
  証券口座を保有している場合、ホーム画面は昨日比・今月比・前年比に代えてこの2指標を表示します。
- **今月の収支とは分離** … 投資の評価損益・元本増減・銀行⇔証券の振替・積立・購入は「今月の収支（収入 − 支出）」には
  一切含めません。株価やインデックスの評価額が上下しても今月の収入・支出・収支は変わらず、評価損益は
  **投資状況カード・証券口座画面・合計資産の内訳** にのみ反映します。株式の売却益・配当金も自動では収支に
  含めず、利用者が収入取引として明示的に登録した場合のみ今月の収入へ反映します。ホーム画面は
  `今月の収支`（収入・支出・収支差額）と `投資状況`（元本・評価額・評価損益・利益率）を別カードで表示します。
- **個別株購入** … 購入金額(円)＝`株数 × 購入単価(USD) × ドル円`。現金を減らし、取得数量・取得単価へ反映します。
- **インデックス積立（任意）** … `accumulations[]` にON/OFF・毎日の積立額・開始/終了日を保存。**日本時間23:00**を境に
  前回処理日から当日まで日ごとに追いかけて実行し、現金から積立額を引いて対象ファンドの総元本・保有額へ加算、
  成否を `accumHistory[]`（成功／失敗（現金不足））に記録します（設定した場合のみ動作）。

金額を変更・保存すると `store.update()` → 再描画で即座に全指標へ反映されます（`securities.js` は純粋関数中心の独立モジュール）。

データはすべて利用端末のブラウザ内（localStorage・ログイン端末ごと）に保存され、再読み込みでも消えません。外部送信は行いません。
